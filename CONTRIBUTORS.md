## How to Get Listed

1. **Code contributions** — open a pull request following
   [`CONTRIBUTING.md`](./CONTRIBUTING.md). Merged PRs earn you a spot in
   the Contributors section.
2. **Security reports** — report a vulnerability privately via a
   [GitHub Security Advisory](https://github.com/ahmedkobbi/smart-edms/security/advisories/new).
   Confirmed reports earn you a spot in the Security Researchers section
   and [`docs/SECURITY-HALL-OF-FAME.md`](./docs/SECURITY-HALL-OF-FAME.md).
3. **Translations** — contribute to `messages/*.json` or review AI-assisted
   translations. Significant contributions earn you a spot in the
   Translators section as a locale maintainer.

All contributors are expected to follow the
[Code of Conduct](./CODE_OF_CONDUCT.md).

---

## Recognition Principles

The Author values **craftsmanship over volume**. One well-tested,
well-documented pull request is worth more than ten rushed ones.
Recognition is based on the impact and quality of the contribution, not
the number of commits.

Contributors will be:
- **Credited** in the relevant commit, PR, or Security Advisory
- **Listed** in this file (unless they request anonymity)
- **Thanked** in the release notes of the release that includes their work
