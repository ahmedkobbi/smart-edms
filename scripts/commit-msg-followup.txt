## #3: Security-regression unit tests for new infrastructure

New `tests/unit/security-regression.test.ts` — 34 tests covering:

- Challenge store (in-memory): set/get/delete/has, TTL expiry, namespace isolation
- SSRF safe fetch: SsrfError class, blocked host detection, URL protocol validation
- Rate limiter (in-memory): strict cap, remaining count, key isolation, reset
- Signed-URL session binding: u= param in HMAC payload, signature differs from
  legacy, cross-user replay prevented
- Client checksum verification: sha256 determinism, timingSafeEqualStr,
  truncated upload detection, hex format validation

These tests are designed to catch regressions if a future refactor accidentally
weakens the security guarantees of the new infrastructure modules.
