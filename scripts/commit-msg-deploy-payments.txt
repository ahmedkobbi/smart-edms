## #5: NowPayments E2E contract tests

New `tests/unit/nowpayments-e2e.test.ts` — 50 tests covering the full
payment flow as contract tests (test the logic without hitting the real
NowPayments API):

1. **Zero Client Trust** (6 tests) — server-side price computation for
   all plans + billing cycles; rejects unknown plans; annual < 12× monthly
2. **Idempotency** (3 tests) — UUID format; same key → same hash;
   different keys → different hashes
3. **Webhook Signature Verification** (7 tests) — correct signature passes;
   wrong secret rejected; tampered body (status change) rejected; tampered
   body (amount change) rejected; missing signature rejected; missing
   secret rejected; key order independence
4. **Status Machine** (10 tests) — all valid transitions allowed;
   confirmed→pending rejected; failed→confirmed rejected;
   expired→anything rejected; refunded→anything rejected; terminal status
   detection
5. **Underpayment Protection** (5 tests) — full payment OK; overpayment OK;
   underpayment blocked; zero payment blocked; underpaid maps to
   `confirming` not `confirmed`
6. **Replay Protection** (3 tests) — same payment_id+status = same dedup
   key; different status = different key; different payment_id = different
   key
7. **Status Mapping** (8 tests) — all NowPayments statuses mapped
   correctly; unknown defaults to `waiting` (safe)
8. **IP Allowlist** (2 tests) — any IP allowed when not configured;
   non-allowlisted IPs rejected when configured
9. **Plan Limits** (8 tests) — all 4 plans tested at limit + over-limit
10. **Configuration Detection** (2 tests) — isNowPaymentsConfigured
    returns boolean
