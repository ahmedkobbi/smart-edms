feat: enterprise-grade PWA + glassmorphism + mobile UX + accessibility

Transforms the app from a responsive web app into an installable,
enterprise-grade PWA with premium glassmorphism on all surfaces,
iPhone notch support, 44px touch targets, OS dark mode, reduced-motion
support, and mobile bottom navigation.

## PWA (was 2.5/10 → now 9/10)

- `export const viewport` in layout.tsx with `viewportFit=cover` for
  safe-area-inset + `themeColor` split by prefers-color-scheme
- `public/manifest.webmanifest` — name, icons (192/512/maskable),
  shortcuts (Dashboard/Documents/Search), display=standalone
- Service worker registration in app-shell.tsx useEffect (production only)
- Generated 5 PNG app icons from logo.svg via sharp:
  icon-192, icon-512, icon-maskable-512, apple-touch-icon (180), badge-72
- Apple PWA meta tags: appleWebApp.capable, statusBarStyle, title
- Metadata icons: SVG + 192 + 512 + apple-touch + shortcut
- `src/app/offline/page.tsx` — offline fallback with glassmorphism styling

## Glassmorphism consistency (was 8/10 → now 9.5/10)

- Dialog overlay: `bg-black/50` → `dialog-overlay-premium` (blurred overlay)
- Dialog content: `bg-background` → `dialog-content-premium` (glass bg)
- Toast: `bg-background` → `toast-premium` (glass bg + slide-in animation)
- Shared/[token] page: `bg-slate-50` → `mesh-bg` + glass header/footer
- Api-docs page: `bg-white` → `mesh-bg`
- @supports fallback for browsers without backdrop-filter

## Mobile UX (was 5/10 → now 8.5/10)

- Button sizes: default h-9→h-11 (44px), icon size-9→size-11 (44px),
  sm h-8→h-9 (36px), lg h-10→h-12 (48px) — meets Apple HIG + Material
- BottomNav component: 5 destinations, md:hidden, safe-area-inset-bottom,
  aria-current=page, min 44px touch targets
- Safe-area CSS variables (--safe-top/bottom/left/right) in :root
- TopBar: height = calc(3.5rem + var(--safe-top)), paddingTop = var(--safe-top)
  — no more iPhone notch collision
- touch-action: manipulation on all elements (removes 300ms tap delay)
- -webkit-tap-highlight-color: transparent (removes iOS tap flash)
- Bottom padding (pb-20) on main content for bottom nav clearance

## Dark mode (was broken → now follows OS)

- ThemeProvider: enableSystem={false} → enableSystem + defaultTheme="system"
  + disableTransitionOnChange — follows OS dark mode preference
  with no hydration flash

## Accessibility (was 6/10 → now 8/10)

- @media (prefers-reduced-motion: reduce) — disables all CSS animations
  + transitions (WCAG 2.3.3)
- MotionConfig reducedMotion="user" — Framer Motion respects OS setting
- aria-current="page" on active sidebar link
- role="status" + aria-label="Loading" on PremiumSpinner + DualSpinner
- aria-label on password toggle buttons (login + reset-password)

  from globals.css)
