feat: comprehensive audit event labels (128 types × 5 locales)

Phase C part 2 — Audit event labels.

**Gap:** Only ~23 event types had labels, and only in en/ar. ~60+ event
types fell through to the raw machine-readable code (e.g. "ai.pii.detected"
displayed as-is in the audit timeline).

**Implemented:**
- New `src/components/audit/audit-event-labels.ts` — auto-generated from
  `scripts/generate-audit-labels.py`. Covers 128 event types × 5 locales
  (en, fr, ar, es, de) = 640 translated labels.
- Categories covered:
  - Authentication (login, logout, password reset, step-up, concurrent session)
  - Authorization (deny, policy.deny, policy.violation)
  - Document lifecycle (read, create, upload, update, delete, download,
    preview, redact, lock, unlock, classify, crypto_shred, close, copy,
    version.create, version.restore, record.declare)
  - Sharing (create, view, revoke)
  - Workflow (create, approve, delegate, escalation.run)
  - Admin — Users (create, update, suspend)
  - Admin — Roles & Groups (create, update, delete)
  - Admin — Policies & Classifications (create, update, delete, localization)
  - Admin — Retention & Legal Hold (create, update, delete, release)
  - Admin — Dispositions (create, approve)
  - Admin — Integrations (API keys, service accounts, webhooks, SSO)
  - Admin — Tenant (create, update)
  - Admin — Other (key rotation, search reindex, metadata schemas, vocab,
    notification routing)
  - Billing (update)
  - Break-glass (request, granted)
  - Dual control (request, decide)
  - Recertification (create)
  - Invitations (create, sent, accepted)
  - AI (suggestion, PII detection, summarization, metadata, policy risk)
  - Audit (export, verify, receipt generate)
  - Evidence (generate)
  - Folders (create, apply classification)
  - Device (revoked, update)
  - Session (revoke all)
  - User self-service (password change, MFA, locale, profile)
  - Passkey (register)
  - Anomaly (resolved)
  - Collaboration (join)
  - Errors (api.error)
- Updated `audit-timeline.tsx` to use the new comprehensive label file
  instead of the hardcoded 23-event map.
- The generator script is idempotent and can be re-run when new event
  types are added to the codebase.
