## Fixes

### #7 — Logout wiring (CRITICAL functional bug)
- Top-bar "Sign out" was calling `signOut()` directly, bypassing the
  custom `/api/auth/logout` endpoint. This meant the JWT was never
  revoked (no `RevokedSession` entry) and no `auth.logout` audit event
  was recorded.
- Fixed: now calls `fetch('/api/auth/logout', { method: 'POST' })`
  first (which revokes the JWT + audits), then `signOut()` to clear
  the cookie and redirect.

### #4 — Saved searches GET-by-id + PUT-update
- `src/app/api/saved-searches/[id]/route.ts` had only DELETE.
- Added `GET` (fetch single saved search by ID) and `PUT` (update
  name, query, or filters). Both tenant + user scoped.

### #3 — External recipient locale
- Added `recipientLocale String?` field to `Share` model.
- Share API now accepts `recipientLocale` in the create payload and
  stores it on the Share record.
- External share email uses `body.recipientLocale` when available,
  falling back to the sharer's locale (previous behavior).

### #10 — Concurrent session blocking
- Was warn-only (>10 logins/hour → audit event with `result: 'allow'`).
- Now: >10 logins/hour → warning (unchanged). >20 logins/hour →
  **BLOCK** the login, revoke all existing sessions, throw error.
  This prevents credential-stuffing and session-sharing attacks.
