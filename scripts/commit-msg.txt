## MEDIUM items

### M1 — Browser push notifications
- New `PushSubscription` Prisma model (endpoint, p256dhKey, authKey)
- `src/lib/notifications/push.ts` — web-push integration with VAPID key
  management (auto-generates keys in dev, uses env vars in prod)
- API: `POST/DELETE /api/push/subscribe`, `GET /api/push/vapid-public-key`
- Wired into `notify()` — warning/critical notifications trigger push
  alongside WebSocket + email
- Service worker (`public/sw-push.js`) — handles push events, notification
  click (opens URL), push subscription change (re-subscribes)
- Docker: VAPID env vars in docker-compose

### M2 — ClamAV real integration
- Replaced the stub `scanWithClamAv()` with a real TCP socket implementation
  using ClamAV's INSTREAM protocol (64KB chunks, 30s timeout)
- Parses response: "OK" → clean, "FOUND" → infected (with threat name),
  "ERROR" → scan error
- Returns `{ status: 'clean', scanner: 'none' }` when CLAMAV_HOST not set
  (heuristic scanner still runs as fallback)
- Docker: `clamav/clamav:latest` service in docker-compose with healthcheck
  and `clamav_data` volume
- Env: `CLAMAV_HOST` + `CLAMAV_PORT` configured for app + worker

### M3 — Accessibility tooling

  label-has-associated-control, no-access-key, no-distracting-elements, scope,
  tabindex-no-positive, etc.)
- `@axe-core/playwright` installed
- `tests/e2e/accessibility.spec.ts` — axe-core audits for login page (LTR +

### M4 — Redaction preview
- New `POST /api/documents/:id/redact-preview` endpoint
- Renders a preview of the redacted derivative WITHOUT creating a new version
- Image: sharp composites black rectangles over redaction regions
- PDF: pdfjs-dist rasterizes the requested page to PNG, then sharp composites
  redaction rectangles
- Returns base64-encoded preview image (data URI)
- Client can display this before committing via POST /redact

### M5 — Translation management
- New API: `GET/POST /api/admin/translations`, `PATCH/DELETE /api/admin/translations/:id`
  — full CRUD for the existing `LocaleResource` model
- Rewrote admin locales page as an enterprise translation management UI:
  - Create/edit/delete translation overrides per locale + namespace + key
  - Filter by locale and review status (draft/reviewed/approved)
  - Approve workflow (draft → reviewed → approved)
  - Inline edit with save/cancel
  - Locale status cards showing key counts per locale
  - RTL-aware text inputs for Arabic overrides

### L3 — SAML SSO
- Installed `@node-saml/passport-saml` dependency
- SSO init route now handles SAML: generates AuthnRequest redirect URL
  using `Strategy.authenticateToIdp()`
- SSO callback route now handles SAML POST binding: parses SAMLResponse,
  verifies via `Strategy.validatePostResponse()`, extracts email + name
  from SAML attributes

  on the same user lookup + JIT provisioning + JWT minting + cookie set

  entry point, entityId = issuer, jwksUri = IdP public cert)
