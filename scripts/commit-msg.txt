## Hardware-key enforcement (§9.1)

**Gap:** `webauthn.ts` captured `backedUp` on passkey registration but
never enforced it. No code required tenant_admin / security_officer roles
to have a hardware-backed passkey.

**Implemented:**
- New `src/lib/auth/hardware-key-enforcement.ts` module:
  - `hasPasskey(userId)` — checks if user has any passkey
  - `hasHardwareBackedPasskey(userId, requireTrueHardwareKey)` — checks
    for hardware-backed or device-bound credentials
  - `requiresHardwareKey(tenantId, userId, roles)` — checks tenant
    setting `security.requireHardwareKeyForHighPrivilegeRoles` + user
    has a high-privilege role
  - `enforceHardwareKey({ tenantId, userId, roles })` — combined check
    that returns `{ ok: true }` or `{ ok: false, reason }`
- Wired into `createApiHandler`: after RBAC + ABAC checks pass, the
  handler calls `enforceHardwareKey()`. If the user is a high-privilege
  role AND the tenant has enforcement enabled AND the user has no
  passkey, the request is rejected with 403 `hardware_key_required`.
- Two enforcement modes:
  - Default: any passkey counts (platform-backed or device-bound)
  - Strict (`settings.security.requireTrueHardwareKey`): only device-bound
    credentials (`backedUp === false`) count — these cannot be synced
    or phished

## Arabic search synonyms (§9.10)

**Gap:** Arabic search had normalization + stopwords but no synonym
expansion. Searching for "عقد" (contract) wouldn't find documents
containing "اتفاقيه" (agreement).

**Implemented:**
- New `expandArabicSynonyms(text)` function in `arabic-search.ts`:
  - Tokenizes the query, looks up each token in the synonym dictionary
  - Appends all synonyms to the query string
  - 30+ synonym entries covering: document types (مستند/وثيقه/ملف),
    actions (توقيع/امضاء/موافقه), classification (سري/محظور/مكتوم),
    legal (قانوني/شرعي), status (مغلق/منتهي, نشط/فعال), people
    (مدير/مسؤول), organizations (شركه/مؤسسه)
  - Only expands Arabic queries (English passes through unchanged)
- Wired into the search API: `expandArabicSynonyms(q.q)` is called
  before passing the query to OpenSearch, so documents containing
  synonym variants are also matched
