feat: enterprise-grade OCR pipeline — pdfjs-dist rasterization, confidence tracking, per-tenant config, audit events, franc language detection

Complete rewrite of the OCR + text extraction pipeline to enterprise-grade.

## What was broken (before)
- Scanned PDF OCR was non-functional (passed raw PDF bytes to tesseract as PNG)
- PDF text extraction used regex on latin1 (failed on CID fonts + FlateDecode)
- OOXML extraction used regex on latin1 of a ZIP (never decompressed)
- No OCR confidence tracking
- No OCR audit events
- Original OCR text was discarded (only normalized form persisted)
- No per-tenant language selection (hardcoded eng+ara)
- New version uploads + restores didn't re-index
- Language detection was a crude Arabic-ratio heuristic

## What's fixed (after)

### 1. PDF text extraction (pdfjs-dist)
- Uses `pdfjs-dist/legacy/build/pdf.mjs` `getDocument()` + `getTextContent()`
- Handles CID fonts, FlateDecode, and all modern PDF features
- Caps at 100 pages for performance

### 2. Scanned PDF OCR (pdfjs-dist page rasterization → tesseract per page)
- Loads PDF with pdfjs-dist
- Renders each page to a PNG canvas at configurable DPI (default 300)
- Runs tesseract CLI on each page image with TSV output
- Concatenates per-page text + computes per-page confidence
- Caps at configurable maxPages (default 50)

### 3. Image OCR
- Passes image buffer directly to tesseract with TSV output
- Extracts word-level text + confidence

### 4. OOXML/ODF text extraction (JSZip + XML parsing)
- Uses JSZip to decompress .docx/.xlsx/.pptx/.odf files
- Extracts text from `w:t` (Word), `a:t` (PowerPoint), `v`/`t` (Excel),
  `text:h`/`text:p` (ODF) elements
- Also reads headers, footers, shared strings, and worksheet cells

### 5. OCR confidence tracking
- Tesseract TSV output parsed for word-level confidence
- Mean confidence stored on `DocumentTextIndex.ocrConfidence`
- Per-page confidences stored as JSON array
- Documents below `minConfidence` (default 70%) marked as `low_confidence`

### 6. Raw text persistence
- `DocumentTextIndex.rawText` stores original extracted/OCR text
- `extractedText` stores normalized form for search indexing
- Display snippets, AI/PII/summarization use rawText (preserves case)
- Search uses extractedText (normalized for matching)

### 7. OCR audit events
- `document.ocr.started` — emitted before OCR begins (with config)
- `document.ocr.completed` — emitted on success (with confidence, duration)
- `document.ocr.failed` — emitted on failure (with error message)

### 8. Per-tenant OCR configuration
- `Tenant.settings.ocr` JSON object:
  - `languages: string[]` — e.g. ['eng', 'ara', 'fra']
  - `dpi: number` — render DPI for PDF rasterization (default 300)
  - `maxPages: number` — max pages to OCR (default 50)
  - `minConfidence: number` — below this %, mark as low_confidence (default 70)
- Admin UI: language toggle buttons (English, Arabic, French, Spanish, German),
  DPI input, maxPages input, minConfidence input
- All 5 Dockerfile language packs (eng, ara, fra, spa, deu) now actually used

### 9. Language detection (franc)
- Uses `franc` library for ISO 639-3 language detection
- Maps franc codes to our supported locales (eng→en, ara→ar, fra→fr, spa→es, deu→de)
- Falls back to Arabic-character-ratio heuristic if franc is unavailable
- Runs after text extraction/OCR to set document language metadata

### 10. Re-OCR on version upload + restore
- `POST /api/documents/:id/versions` now calls `indexDocumentText()` + `osIndexDocument()`
- `POST /api/documents/:id/versions/:vid/restore` now calls both too
- Text index stays current with the latest version

### 11. OCR status on Document model
- New `ocrStatus` field: `pending | processing | success | failed | low_confidence | skipped`
- Updated at each stage of the OCR pipeline
- Can be surfaced in the document detail UI as a status badge

### 12. Schema changes
- `DocumentTextIndex`: added `rawText`, `ocrConfidence`, `ocrPageConfidences`,
  `ocrEngine`, `ocrLanguages`, `ocrDurationMs`
- `Document`: added `ocrStatus` field
- New dependencies: `jszip` (OOXML extraction), `franc` (language detection)
